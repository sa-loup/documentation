PHASE 1 — Préparation (Obligatoire)

Avant tout, active les modules nécessaires :

Aller à :

eLearning → Configuration → Settings

Active :

Certifications

Paid Courses (si tu veux vendre ton cours, sinon facultatif)

Mailing (facultatif)

Forum (facultatif)

Clique sur Save.

PHASE 2 — Créer un cours complet

(menu : eLearning → Courses → Courses → New)

Voici les réglages RECOMMANDÉS :

A. Information générale

Course Title :
Introduction à Odoo 18 – Utilisation Fonctionnelle

Tags :
Odoo, ERP, Fonctionnel, Débutant

Image :
Ajoute une image/gif Canva si tu veux (tu peux m’en demander un).

B. Contenu du cours

Va dans l’onglet Content.

1) Ajouter les sections

Cliquer Add Section puis créer :

Introduction

Découverte d’Odoo

Gestion des utilisateurs

Ventes

Facturation

Test final & Certification

2) Ajouter du contenu dans chaque section

Dans chaque section → Add Content

Voici la liste des contenus prêts à copier-coller :

Section : TEST FINAL & CERTIFICATION

Type : Quiz

Créer un quiz avec 5 questions :

Odoo est :
A. Un ERP
B. Une boutique
C. Un réseau social
→ Bonne réponse : A

Quel module permet de créer un devis ?
→ Réponse : Sales

Quel document valide la facturation ?
→ Réponse : Facture validée

Quelle vue permet de voir les étapes ?
→ Réponse : Kanban

Quel rôle donne tous les accès ?
→ Réponse : Manager

Score minimum : 60%

PHASE 3 — Créer le certificat (fonctionne à 100 %)

Très important :
Les certificats se créent dans Survey, mais ensuite ils apparaissent dans eLearning.

Aller à :

Survey → New → Type = Certification

Ensuite :

1) Nom :

Certificat – Odoo 18 Utilisation Fonctionnelle

2) Onglet Questions

Tu n’as besoin d’aucune question ici (c’est normal).
Le Quiz du cours sert d’examen.

3) Onglet Options

Activer :

Notes

Certificat PDF

Mettre :

Scoring : Based on eLearning quiz (si existant)

4) Message de fin

Copier-coller :

Félicitations !
Vous avez réussi la certification « Odoo 18 – Utilisation Fonctionnelle ».
Votre certificat est maintenant disponible en téléchargement.

PHASE 4 — Lier le certificat au Quiz du cours

Retourne au Quiz (dans ton cours → contenu → Quiz → Options).

Dans « Options » :

Certification : sélectionne ton certificat « Certificat – Odoo 18 »

Score minimum : 60%

Tentatives : Illimité

Enregistrer.

PHASE 5 — Publier sur ton site web
Aller au front-end :

Dans ton cours → bouton Go To Website

Publier chaque contenu :
→ En haut à droite bouton : Unpublished → Published

Publier le cours :
→ Même bouton

Ton cours sera maintenant visible sur ton site web :

/courses

Les utilisateurs pourront :

S’inscrire

Faire les leçons

Faire le test final

Télécharger le certificat automatiquement
